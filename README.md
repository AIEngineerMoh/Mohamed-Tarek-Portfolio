# Mohamed Tarek — Personal Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS, and JavaScript. No build step or framework is required.

## 1) Run locally
Open `index.html` in your browser, or use the VS Code Live Server extension.

## 2) Add your CV
Place your PDF at:
`assets/Mohamed_Tarek_CV.pdf`
The Download CV links already point to that path.

## 3) Personalize before publishing
- Replace the generic GitHub profile links on project cards with the exact repository URLs.
- Check the LinkedIn URL and certificate links.
- Add your preferred public contact email if you want an email button.
- Review the wording of skills, education, and project descriptions so every claim matches your actual experience.
- Add project screenshots in `assets/` if you want to replace the CSS-made preview illustrations.

## 4) Deploy on Render (Static Site)
1. Push this folder to a GitHub repository.
2. In Render, choose **New + → Static Site** and connect the repository.
3. Set **Build Command** to blank (or `echo "Static site"` if the form requires one).
4. Set **Publish Directory** to `.`.
5. Click **Create Static Site**.

## Files
- `index.html` — page content
- `styles.css` — responsive dark/neon styling
- `script.js` — mobile navigation and current year
- `assets/` — put your CV PDF here
